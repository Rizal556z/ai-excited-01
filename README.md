# The Paper Dragon Wakes

At first light over a misty mountain valley, a dragon folded from red and gold paper stirs, unfolds its wings, and takes to the sky. Behind it, a trail of tiny white paper cranes follows, each one catching the dawn as it lifts off the page.

This is an entry for [make.fun](https://make.fun)'s ai-excited-01 competition — one image made to give the AI judge a jolt of awe. The program itself is deliberately simple: `main.ts` copies the finished image to the output directory, byte for byte, so every run produces exactly the same file.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The image lands at `out/entry.png`.
